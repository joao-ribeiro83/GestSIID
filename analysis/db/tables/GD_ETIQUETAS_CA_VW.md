## View SQL text

```sql
SELECT   ETIQUETAS.CDNMPROC
         ,MOVIMENTO.NMPROAME
		 ,MOVIMENTO.NMCOMAME
		 ,MOVIMENTO.NMORDEN
		 ,ENTIDADE_DEVEDORA.DSNOMBRE NOME_DEVEDOR
         ,ENTIDADE_DEVEDORA.CDIDEPER NIPC_NUREPA
		 ,ETIQUETAS.N_REFERENCIA
    FROM MPERSONA ENTIDADE_DEVEDORA
        ,CO_PRCON PROCESSO
		,GD_ETIQUETAS_CA ETIQUETAS
		,CO_MVCON MOVIMENTO
   WHERE PROCESSO.CDNMPROC = ETIQUETAS.CDNMPROC
     AND ENTIDADE_DEVEDORA.CDPERSON = PROCESSO.CDPERSON
	 AND MOVIMENTO.CDNMPROC = ETIQUETAS.CDNMPROC
	 AND MOVIMENTO.NMORDEN  = ETIQUETAS.NMORDEN
	 AND ETIQUETAS.IMPRESSO = 'N'

```
